Source notices for the chiral SU(5) proof

The license files in this directory apply to the materials identified in the source notices.

This proof incorporates code from OpenAI's Wilson Yang–Mills formalization.
The upstream project released its original code under the Apache License,
Version 2.0. Wilson-source-notices.tsv identifies the corresponding modules
and records changes. Wilson-Yang-Mills-LICENSE.txt contains the full license.

Mathlib-source-notices.tsv identifies adapted Mathlib passages, their authors
and their copyright notices. Mathlib-LICENSE.txt contains the full license.
In both tables, archive_path is relative to this project. The Wilson table
also gives the path in the original Wilson project. The Mathlib table
links to the corresponding upstream sources.

The massive QCD Lean proof distribution contains passages also used in this proof.
Massive-QCD-source-notices.tsv identifies the files and lines in both projects
and gives the SHA-256 of each complete source file in the QCD distribution.
Passages that also occur in the Wilson distribution are credited in both tables.

The project uses Lean, Lake and the pinned libraries in lake-manifest.json.
The toolchains and these libraries are installed separately.
